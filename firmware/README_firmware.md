# Firmware PhysioScan — ESP32

## Librerías requeridas (Arduino IDE / PlatformIO)

- `TinyGPSPlus` (Mikal Hart)
- `MPU6050` (Electronic Cats)

## Instalación rápida

1. Instala soporte ESP32 en Arduino IDE.
2. Instala las librerías anteriores desde el Gestor de Librerías.
3. Copia `config.h.example` → `config.h` y completa con la IP LAN del PC.
4. Carga el sketch. Abre Serial Monitor a 115200 baud.
